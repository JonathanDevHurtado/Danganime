## Correcciones de Errores (Bug Fixes)

### Fix: Carácter 'n' extra en AD_BLOCK_CSS

**Problema**: La constante `AD_BLOCK_CSS` comenzaba con un carácter 'n' que causaba CSS inválido.

**Causa**: Error de tipeo al concatenar strings.

**Solución**:
```java
// Antes
private static final String AD_BLOCK_CSS = "n" +
    ".adsbygoogle, [id*='google_ads']..."

// Después
private static final String AD_BLOCK_CSS =
    ".adsbygoogle, [id*='google_ads']..."
```

**Archivo**: `MainActivity.java:65`

---

### Fix: closeWebView comportamiento inconsistente

**Problema**: Al cerrar el visor de sitios, para categorías con 1 sitio se volvía directamente al menú sin mostrar el selector.

**Solución**: Ahora siempre muestra el selector de sitios si hay una categoría activa.

```javascript
// Antes
if (currentCategory && SITES[currentCategory].sites.length > 1) {

// Después
if (currentCategory) {
```

**Archivo**: `app.js:249-261`

---

### Fix: Footer con versión incorrecta

**Problema**: El footer mostraba "Danganime v1.0" en lugar de la versión actual.

**Solución**: Actualizado a "Danganime v1.2.0".

**Archivo**: `index.html:60`

---

### Fix: Welcome sound no se reproduce

**Problema**: El sonido de bienvenida no se escuchaba porque el AudioContext estaba suspendido.

**Causa**: Los navegadores requieren interacción del usuario antes de reproducir audio.

**Solución**: Se llama a `ensureContext()` antes de reproducir el audio para forzar la activación del AudioContext.

**Archivo**: `sounds.js:95-104`

## Correcciones de Seguridad

### Fix: AllowUniversalAccessFromFileURLs

**Problema**: Las configuraciones `AllowFileAccessFromFileURLs` y `AllowUniversalAccessFromFileURLs` estaban habilitadas, lo que permitía que cualquier archivo local accediera a cualquier origen.

**Riesgo**: Un archivo malicioso podría acceder a datos de otros archivos o servicios.

**Solución**:
```java
// Antes
settings.setAllowFileAccessFromFileURLs(true);
settings.setAllowUniversalAccessFromFileURLs(true);

// Después
settings.setAllowFileAccessFromFileURLs(false);
settings.setAllowUniversalAccessFromFileURLs(false);
```

**Archivo**: `MainActivity.java:100-103`

**Impacto**: Las iframes de sitios externos ahora cargan correctamente sin permisos de acceso excesivo.

---

### Fix: Variable no utilizada

**Problema**: La variable `mainWebView` estaba declarada pero nunca usada.

**Solución**: Eliminada la declaración innecesaria.

**Archivo**: `MainActivity.java`
