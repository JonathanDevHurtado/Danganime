# v1.9.0 - Pluto TV: mostrar la barra de reproducción en pantalla completa

**Fecha**: 16/09/2026

---

## Problema

En **pantalla completa** de Pluto TV no aparecía la **barra de reproducción**. El
reproductor (Avia/Kaltura) ocultaba su elemento `<avia-control-bar>` con
`display: none` (y no la mostraba al tocar).

## Diagnóstico

- Se comprobó que **no es culpa de la app**: ni desactivando nuestro JS ni quitando
  nuestro CSS, la barra seguía oculta (`avia-control-bar` con `display: none`).
- Ninguno de nuestros selectores CSS coincidía con el reproductor ni sus ancestros.

## Solución

Se añade una regla CSS que **fuerza visible** la barra de controles de Avia:

```css
avia-control-bar {
  display: flex !important;
  opacity: 1 !important;
  visibility: visible !important;
}
```

Es específica del reproductor Avia (Pluto), así que no afecta al resto de sitios.
