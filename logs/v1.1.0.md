## Correcciones de Errores (Bug Fixes)

### Fix: Logo no aparecía en Splash Screen
**Problema**: El logo no se mostraba en la pantalla de inicio.

**Causa**: El contenedor del logo no tenía las propiedades correctas de flexbox y dimensiones.

**Solución**:
```css
/* Antes */
.splash-logo {
  width: 150px;
  height: 150px;
}

/* Después */
.splash-logo-container {
  width: 160px;
  height: 160px;
  border-radius: 50%;
  overflow: hidden;
  background: rgba(255, 255, 255, 0.05);
  display: flex;
  align-items: center;
  justify-content: center;
}

.splash-logo-img {
  width: 100%;
  height: 100%;
  object-fit: cover;
  border-radius: 50%;
}
```

**Archivos**: `www/css/style.css`, `www/index.html`
