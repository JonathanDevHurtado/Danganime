# v1.6.5 - Fix guard anti-popunder (no romper reproductores) + ad domain

**Fecha**: 09/09/2026

---

## Problema

Tras el guard anti-popunder (v1.6.2), **algunos reproductores no cargaban**: el guard cancelaba navegaciones top-level legítimas a servidores de video cuyo host no estaba en `SAFE_BASES` (p. ej. `streamnova-zone.com`, que **sí** es un servidor de video).

Además, llegó una página de anuncio nueva: `stareobjectedcipher.com/api/users?...`.

## Solución

1. **Guard más inteligente**: antes de cancelar una navegación sin gesto, se permite si el host "parece reproductor" (contiene `stream`, `vid`, `player`, `embed`, `play`, `watch`, `cdn`, `video`, `file`, `moon`, `drop`, `share`, `tape`, `nova`, `lulu`, `dood`, `mix`, `mp4`, `voe`, `upn`, `byse`, `hex`, `save`, `zilla`, etc.).
   - Navegación a host tipo reproductor → **permitida**.
   - Navegación a dominio aleatorio de anuncios → **cancelada**.
2. Añadido `streamnova.to/.net/-zone.com` a `SAFE_BASES`.
3. Añadido `stareobjectedcipher.com` a la lista de bloqueo.
