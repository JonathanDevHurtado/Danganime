# v1.0.0 - Versión Inicial

**Fecha**: 09/09/2026

---

## Descripción

Primera versión funcional de la aplicación Danganime.

---

## Nuevas Funcionalidades

### Splash Screen
- Logo animado con efecto bounce
- Título "Danganime" con degradado brillante
- Subtítulo "Anime • Manhwa • Manga"
- Transición suave al menú principal

### Menú Principal
- 3 tarjetas de categorías (Anime, Manhwa, Manga)
- Animaciones bounce escalonadas
- Colores diferenciados por categoría
- Borde lateral neon

### Selector de Sitios
- Lista de sitios por categoría
- Animación de entrada deslizante
- Badges informativos

### Visor de Sitios (WebView)
- Barra de herramientas completa
- Botones: regresar, recargar, abrir externo
- Indicador de carga animado

### Efectos de Sonido
- Web Audio API para generar sonidos
- Sonidos: click, tap, open, back, splash

### Bloqueo de Anuncios
- CSS injection para ocultar elementos
- JavaScript injection para bloquear requests
- 70+ dominios bloqueados en Android
