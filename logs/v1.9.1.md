# v1.9.1 - Fix barra de reproducción de Pluto (layout en columna)

**Fecha**: 16/09/2026

---

## Problema

En v1.9.0 se forzó `avia-control-bar` con `display: flex`, pero eso **rompió el layout**:
el contenedor usa **columna**, así que al forzar fila el **slider de progreso quedaba en
0 de ancho** y la barra no se veía bien (ni en vertical ni en horizontal).

## Solución

Se corrige la regla CSS añadiendo `flex-direction: column`:

```css
avia-control-bar {
  display: flex !important;
  flex-direction: column !important;
  opacity: 1 !important;
  visibility: visible !important;
}
```

Así el slider recupera todo su ancho y la barra se muestra completa.

|---|---|---|
| Vertical (392×824) | ✅ 393×66 | ✅ 369 px |
| Horizontal (872×344) | ✅ 873×66 | ✅ 849 px |
