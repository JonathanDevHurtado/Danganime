## Correcciones de Errores (Bug Fixes)

### Fix: ERR_CONNECTION_REFUSED

**Problema**: Al abrir la app aparecía el mensaje:
```
La pagina web de https://localhost/ no se pudo cargar porque: 
net:ERR_CONNECTION_REFUSED
```

**Causa**: Capacitor estaba configurado con `androidScheme: "https"`, lo que hacía que el WebView intentara cargar desde `https://localhost` en lugar de archivos locales.

**Solución**:
```json
// Antes
{
  "server": {
    "androidScheme": "https"
  }
}

// Después
{
  "server": {
    "androidScheme": "file"
  },
  "android": {
    "allowMixedContent": true
  }
}
```

**Archivos**: `capacitor.config.json`

---

### Fix: WebView no cargaba contenido local

**Problema**: El WebView no tenía permisos para acceder a archivos locales.

**Solución**: Se agregaron WebSettings adicionales en `MainActivity.java`:

```java
settings.setAllowFileAccess(true);
settings.setAllowContentAccess(true);
settings.setAllowFileAccessFromFileURLs(true);
settings.setAllowUniversalAccessFromFileURLs(true);
settings.setCacheMode(WebSettings.LOAD_DEFAULT);
settings.setMixedContentMode(WebSettings.MIXED_CONTENT_ALWAYS_ALLOW);
```

**Archivos**: `MainActivity.java`

---

### Fix: Acentos en APK

**Problema**: El nombre de la app aparecía como "danganime" en minúsculas.

**Solución**: Actualizar `strings.xml`:
```xml
<!-- Antes -->
<string name="app_name">danganime</string>

<!-- Después -->
<string name="app_name">Danganime</string>
```

**Archivos**: `android/app/src/main/res/values/strings.xml`
